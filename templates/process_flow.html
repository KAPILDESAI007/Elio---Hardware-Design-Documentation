Upload & Process Process Flow

Process Workflow

1

Input: Customer Database

Read Excel file containing PID tags, nodes, slots, and module information

↓
2

Template Setup

Copy template with 2 sheets: Front_Template & FrontLoading

↓
3

Sheet 1: PID Tag Assignment

Front_Template (494-ESD-06_X)

  • Extract PID tags by Node, Slot, and Channel
  • Map tags to corresponding cells in the template
  • Fill Cabinet No and Station Name headers
↓
4

Sheet 2: Module Name Assignment

FrontLoading (SCS0122_FrontLoading)

  • Extract IO_MODULE names by Node and Slot
  • Identify redundancy (mark with R)
  • Place module names in correct merged cells
↓
5

Station Information

Write station name and node information to AM-AN columns for reference

↓
6

Output: Hardware Documentation

Generate single Excel file with both sheets populated and ready for hardware design

Key Points:

  • Node Structure: Each node has 16 channels (1-16) with multiple slots (S1-S8)
  • Merged Cells: Template uses merged cells for channel rows. Code handles this automatically
  • Redundancy: When SLOT_R (redundant slot) is adjacent to SLOT_P, marked as (R)
  • Header Mapping: Cabinet name and station name are extracted and placed in designated cells
  • Error Handling: Gracefully handles missing data and validates all inputs
